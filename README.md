# React + TypeScript API 연동 실습

과제 요구사항인 `fetch`, `axios`, API 응답 화면 출력, 로딩 및 에러 처리를 모두 포함한 예제입니다. API 키 없이 TheCatAPI에서 고양이 사진을 불러옵니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에 표시된 두 버튼을 각각 눌러 고양이 사진을 `fetch`와 `axios` 방식으로 요청해 보세요.

## 핵심 파일

- `src/App.tsx`: API 요청, 로딩/에러 상태 관리, 응답 데이터 출력
- `src/index.css`: 간단한 화면 스타일
